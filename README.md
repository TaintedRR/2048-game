# 2048

Классическая головоломка 2048: двигай плитки, складывай одинаковые числа и собери плитку 2048.

**Играть:** https://taintedrr.github.io/2048-game/

## Возможности

- Плавное движение плиток и анимация слияния.
- Управление стрелками, клавишами WASD (работает в любой раскладке) или свайпами на телефоне.
- Отмена последнего хода (кнопка или Ctrl+Z).
- Счёт с всплывающими очками, рекорд и статистика игр.
- Экраны победы и проигрыша. После победы можно играть дальше.
- Партия сохраняется: можно закрыть вкладку и продолжить позже.
- Интерфейс на русском и английском, переключатель RU / EN в шапке.
- Светлая и тёмная тема.

## Технологии

HTML, CSS, JavaScript без библиотек: CSS-переходы для анимации, Pointer Events для свайпов, `localStorage` для сохранения.

## Запуск

Открой `index.html` в браузере. Сборка не нужна.

## English

The classic 2048 puzzle: slide the tiles, merge equal numbers and reach 2048.

- Smooth tile movement and merge animations.
- Arrow keys, WASD (works in any keyboard layout) or swipes on mobile.
- Undo the last move, score, high score and game stats.
- The game is saved, so you can close the tab and continue later.
- Russian and English interface with an RU / EN switch.
- Plain HTML, CSS and JavaScript. Open `index.html` to play.
